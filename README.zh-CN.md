## 📖 关于

本插件拆分自 **STtools** 插件，将 [tldraw](https://tldraw.dev/) 无限白板能力带入思源笔记。

## ✨ 特性

- 🖌️ 完整的 tldraw 白板功能集成
- 📝 无限画布，自由绘图和制图
- 🔗 与思源笔记文档无缝集成
- 💾 白板数据与文档关联持久化存储

## 🚀 快速开始

### 安装方式

1. 从 [Releases](https://github.com/loonghfut/siyuan-steve-tools/releases) 页面下载最新版本
2. 在思源笔记中通过 `设置 → 集市 → 安装本地插件` 安装

### 使用方式

按以下步骤开始使用白板：

1. **打开插件** — 在思源笔记工作区中打开本插件。

   ![打开插件](https://github.com/loonghfut/siyuan-steve-tldraw/blob/main-2/image.png?raw=true)

2. **点击按钮** — 点击文档右上角按钮，进入白板。

   ![进入白板](https://github.com/loonghfut/siyuan-steve-tldraw/blob/main-2/image-1.png?raw=true)

3. **自由创作** — 基本用法与 tldraw 白板一致。

4. **删除白板** — 先删除对应文档，然后在设置面板中移除。

   ![删除白板](https://github.com/loonghfut/siyuan-steve-tldraw/blob/main-2/image-2.png?raw=true)
