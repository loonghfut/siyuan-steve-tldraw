## 📖 About

This plugin is split from the **STtools** plugin, bringing the power of [tldraw](https://tldraw.dev/) infinite whiteboard into Siyuan Note.

## ✨ Features

- 🖌️ Full-featured tldraw whiteboard integration
- 📝 Infinite canvas for freeform drawing and diagramming
- 🔗 Seamless integration with Siyuan Note documents
- 💾 Persistent whiteboard storage tied to documents

## 📋 Recent Updates

- 🔧 Adapted to Siyuan 1.2.4 `addAgentCapability` API
- ⚡ Fixed save race conditions and optimized rendering performance
- 🧹 Removed deprecated modules and cleaned up redundant code and icons
- 🚀 Improved static preview loading and viewport rendering

## 🚀 Getting Started

### Installation

1. Download the latest release from the [Releases](https://github.com/loonghfut/siyuan-steve-tools/releases) page
2. Install the plugin in Siyuan Note via `Settings → Marketplace → Install local plugin`

### Usage

Follow these steps to start using the whiteboard:

1. **Open the plugin** from the Siyuan Note workspace.

   ![Open Plugin](https://github.com/loonghfut/siyuan-steve-tldraw/blob/main-2/image.png?raw=true)

2. **Click the button** at the top-right of the document to enter the whiteboard.

   ![Enter Whiteboard](https://github.com/loonghfut/siyuan-steve-tldraw/blob/main-2/image-1.png?raw=true)

3. **Draw and create** — basic usage is the same as the tldraw whiteboard.

4. **Delete a whiteboard** — first delete the associated document, then remove it from the Settings panel.

   ![Delete Whiteboard](https://github.com/loonghfut/siyuan-steve-tldraw/blob/main-2/image-2.png?raw=true)
